# TradeNova – Stock Trading Platform

TradeNova is a stock trading web application inspired by Zerodha. It allows users to manage their stock investments and perform demo trading.

## Features

- User Signup and Login
- Secure password hashing
- Buy and Sell stocks
- Watchlist with stock prices
- Holdings and Positions management
- Profit and Loss calculation
- Funds management
- Order history
- Dashboard with investment summary

## Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS, Material UI

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Authentication:** JWT / Cookie-based authentication

**Tools:** Git, GitHub

## Project Functionality

- Users can create an account and log in.
- Users can buy and sell stocks using the available demo prices.
- Holdings and Positions update based on trading activity.
- Profit and Loss are calculated using stock quantity, average buying price, and LTP.
- Orders are stored in the database.

## Market Data

The project currently uses fixed/demo stock prices. Live stock market API integration is not included.

## Future Improvements

- Live stock market API integration
- Real-time stock price updates
- Improved market data visualization

## Disclaimer

TradeNova is an educational demo trading project. It does not execute real stock market transactions.
